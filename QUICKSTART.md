# 🚀 Quick Start Guide

## Run Locally (3 Simple Steps!)

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the app:**
   ```bash
   python app.py
   ```

3. **Open in browser:**
   ```
   http://localhost:5000
   ```

That's it! The romantic proposal app is now running! 💕

## What to Expect

1. **Landing Page** - Beautiful animated entrance with hearts
2. **Proposal Page** - Ask Pavni to be your Valentine with:
   - Countdown timer to Valentine's Day 2026
   - "Yes" button (easy to click)
   - "No" button (moves away when you hover - good luck clicking it! 😄)
   - Music toggle button
3. **Celebration Page** - Confetti and romantic message when she says YES!

## Deploy & Share

### Fastest: Heroku
```bash
heroku login
heroku create your-app-name
git init
git add .
git commit -m "Valentine's Day proposal for Pavni"
git push heroku main
heroku open
```

### Alternative: PythonAnywhere
1. Sign up at pythonanywhere.com
2. Upload files
3. Create Flask web app
4. Configure WSGI file
5. Install requirements
6. Reload app

See README.md for detailed deployment instructions!

## Tips

- ✅ Test locally first
- ✅ The "No" button is intentionally hard to click (it's playful!)
- ✅ Works on mobile and desktop
- ✅ Add music.mp3 to static/audio/ for background music
- ✅ Response is saved to responses.txt when she clicks "Yes"
